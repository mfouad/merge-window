4 ways to put a gate in front of agent actions

01Agent-native gateway
Agent→ MCP-aware gateway→ Tools
Fits when: you are starting fresh and want policies written in terms of tools and agents.
e.g. agentgateway
02Federating registry
Agent→ One catalog→ Many tools
Fits when: tools are sprawling across teams and discovery is the first problem.
e.g. ContextForge
03Identity-aware proxy
User + agent→ Zero-trust proxy→ Tool
Fits when: knowing which human an agent acts for matters most.
e.g. Pomerium
04Extend your proxy
Agent→ Proxy + policy engine→ Tools
Fits when: you already run that proxy and want one less system.
e.g. Envoy AI Gateway + OPA
WHAT TO EVALUATE, WHICHEVER YOU PICK
Identity
Agent and on-behalf-of user
Policy depth
Per tool, per argument
Limits
Rate, quota, cost
Audit
Replayable decisions
Protocols
MCP, A2A, REST
Exit cost
