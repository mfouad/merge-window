# Merge Window brand assets

Generated by `npm run brand` (see `build.mjs`). Edit the script, not the outputs.

- `svg/`: logo marks and lockups (dark, light, transparent, grayscale, `currentColor`), plus `@3x` PNGs in `png/`
- `icons/`: favicon.svg/.ico, apple-touch, Android, maskable, Safari pinned tab, manifest, `head-snippet.html`
- `social/`: LinkedIn banner 1584×396, launch post 1080×1350, newsletter cover 1920×1080, OG image 1200×630, avatar
- `carousel/`: 5 slides, 1080×1350 (SVG + PNG); slide 1 is the launch post

Text in every SVG is outlined from Source Serif 4 / IBM Plex, so no fonts are needed to render them.
Change `ISSUE_LABEL` and `TAGLINE` at the top of `build.mjs` to relabel.
